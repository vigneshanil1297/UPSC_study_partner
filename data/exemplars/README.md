# Topper reference essays

Drop previous-year topper essays here as `.txt` or `.md` files (one essay per
file). They are injected into the evaluation prompt as "what good looks like"
anchors and cached, so repeat evaluations stay cheap.

- Keep it to a handful of strong, diverse samples for now.
- If you only have **images** of topper papers, run them through the Transcribe
  step in the app first, then paste the cleaned text into a file here.
- A few hundred lines total is fine. If this grows large, we'll switch to
  embedding-based retrieval instead of injecting everything.

`sample-essay.md` is a placeholder showing the expected shape — replace it.
